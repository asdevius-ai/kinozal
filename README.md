# Кінозал

Каталог фільмів на даних TMDB: пошук, жанри, рік, сортування, тренди, картки фільмів з акторами, трейлерами та схожими фільмами, обране і "продовжити перегляд".

- `config.js`: мова, регіон і (необов'язково) ключ TMDB. Ключ можна також ввести на самому сайті, тоді він зберігається тільки в браузері.
- `player.js`: функція `resolveStream(movie)`, яку викликає кнопка "Дивитись". Поверни `{ type: 'video', url }` або `{ type: 'iframe', url }`. Якщо вона повертає `null`, показується трейлер і сервіси, де фільм доступний.

Працює як статичний сайт (GitHub Pages), збирати нічого не треба.

This product uses the TMDB API but is not endorsed or certified by TMDB.
